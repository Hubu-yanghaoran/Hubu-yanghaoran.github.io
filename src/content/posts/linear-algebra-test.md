## 1. 什么是向量空间？

向量空间是在一个数域上定义的集合，配备向量加法和标量乘法，并满足相应公理。例如，所有二维实向量组成的集合 R² 是实数域上的向量空间。

对于 u = (1, 2)、v = (3, −1)，有：

- 向量加法：u + v = (4, 1)。
- 标量乘法：2u = (2, 4)。
- 零向量：(0, 0)。

## 2. 线性组合

如果一个向量可以写为若干向量乘以标量后相加的形式，就称它是这些向量的线性组合。

取 e₁ = (1, 0)、e₂ = (0, 1)，则：

```text
(3, 2) = 3e₁ + 2e₂
```

这说明任意二维实向量 (a, b) 都能写成 ae₁ + be₂。

## 3. 基与维数

一组向量如果线性无关，且能够张成整个向量空间，就构成这个空间的一组基。有限维向量空间的一组基所含的向量数称为维数。

e₁、e₂ 构成 R² 的标准基，因此 R² 的维数为 2。

## 4. 小练习

判断 v₁ = (1, 1)、v₂ = (1, −1) 是否构成 R² 的一组基。

提示：由 av₁ + bv₂ = (0, 0)，得到 a + b = 0、a − b = 0，因此 a = b = 0。这两个向量线性无关；又因为 R² 的维数为 2，所以它们构成一组基。
