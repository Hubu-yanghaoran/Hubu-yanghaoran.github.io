Lumina XeLaTeX 中文版

适合中英文数学笔记与讲义。保留原版封面、配色、章节和定理框。上游作者为 Soham Chatterjee；MIT 许可证及版权声明保留在源码包中。

下载与环境

下载源码，解压后打开 main.tex。建议完整 TeX Live，选择 XeLaTeX；不要用 pdfLaTeX。中文字体使用 TeX Live 自带 Fandol，无需 Windows 专有字体。

编译

在项目目录重复执行下面的命令三次，生成目录与交叉引用：

xelatex -interaction=nonstopmode -halt-on-error main.tex

也可运行包内 build.ps1。Overleaf 上传完整项目后，将 main.tex 设为主文档并选择 XeLaTeX；该云端流程尚未实际测试。

修改与布局

在 main.tex 修改标题、作者、课程信息和正文。lumina-xecjk.tex 设置中文字体；config.tex 设置原版颜色；preamble.tex 控制章节、定理框及页眉；title.tex 是封面；macros.tex 与 letterfonts.tex 提供原版命令。保持文件结构完整。

\chapter{数学笔记}
\section{数列}
\dfn[limit]{极限}{这里写定义。}
\thm[unique]{唯一性}{这里写定理。}
\begin{proof}这里写证明。\end{proof}
\nt{这里写备注。}

验证与限制

已在本地 TeX Live 2026 下用 XeLaTeX 编译并检查 5 页示例。少量字体回退、underfull box 和原版相关提示仍存在。Chapter、Definition 等英文装饰标签有意保留；无 Git 元数据时页脚显示 Untracked。新增内容后应重新检查 PDF，生僻字可能需要更完整的中文字体。
